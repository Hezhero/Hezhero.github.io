二、Prompt 工程核心定义与公式

1. 定义

创建Prompt（提问 / 指导）引导 ChatGPT 等语言模型输出的过程，核心是通过清晰引导控制文本相关性、准确性与定制化程度，弥补模型 “无引导时输出不稳定” 的缺陷。

2. 核心公式

Prompt = 任务 + 指令 + 角色

  • 任务：明确模型需生成的内容（如 “生成客户服务响应”“总结新闻文章”）；

  • 指令：模型生成时需遵循的规则（如 “专业准确”“中立客观”）；

  • 角色：模型需扮演的身份（如 “客户服务代表”“律师”“技术专家”）。

三、核心 Prompt 技术分类总结（按章节）

四、核心价值与实践建议

  1. 核心价值：通过 “明确引导” 解决 ChatGPT“无 Prompt 时输出模糊、无关” 的问题，实现 “定制化高质量输出”；

  2. 实践建议：单一技术可满足基础需求，复杂目标需结合多种技术（如 “角色 + 指令 + 种子词”），建议根据具体场景测试不同组合，找到最优方案。

五、关键问题与答案

问题 1：Prompt 工程的核心公式由哪三部分构成？这三部分分别起到什么作用？

答案：Prompt 工程的核心公式是任务 + 指令 + 角色，三部分作用如下：

  • 任务：明确模型需生成的具体内容（如 “生成客户服务响应”“总结新闻文章”），是 Prompt 的 “目标导向”，避免模型输出偏离需求；

  • 指令：规定模型生成文本时需遵循的规则（如 “专业准确”“中立客观”“突出创新特点”），是 Prompt 的 “质量约束”，确保输出符合风格、精度要求；

  • 角色：指定模型需扮演的身份（如 “客户服务代表”“律师”“技术专家”），是 Prompt 的 “场景适配”，让输出贴合特定职业视角或受众需求。
    三者结合可形成 “目标清晰、规则明确、场景适配” 的 Prompt，大幅提升 ChatGPT 输出质量。

问题 2：零样本、一样本、少样本 Prompting 的核心区别是什么？分别适用于哪些实际场景？

答案：三者的核心区别在于 “引导模型时使用的样例数量”，适用场景随样例数量变化：

  • 零样本 Prompting：无任何样例，直接让模型基于对任务的理解生成文本；适用于 “新任务、无参考数据” 的场景，如 “为刚发布的、无历史评论的新智能手表撰写产品描述”；

  • 一样本 Prompting：提供 1 个样例，让模型模仿样例逻辑生成文本；适用于 “任务有少量参考、需统一风格” 的场景，如 “用最新款 iPhone 的评测作为样例，生成新智能手机的对比评测”；

  • 少样本 Prompting：提供 2-5 个（有限数量）样例，让模型归纳样例规律后生成文本；适用于 “任务有少量参考数据、需保证输出一致性” 的场景，如 “用 3 款主流电子阅读器的评论作为样例，生成新电子阅读器的评论”。

问题 3：如何将多种 Prompt 技术结合使用？请结合文档中的示例说明其优势。

答案：结合多种 Prompt 技术的核心逻辑是 “以‘任务’为核心，叠加‘角色’（场景）、‘指令’（质量）、‘种子词’（方向）等要素”，文档中典型示例如下：

  • 结合方案：角色（营销代表）+ 指令（有信息量、有说服力，突出独特特点）+ 种子词（创新的）+ 任务（生成新款智能手机产品描述）；

  • 具体 Prompt 公式：“以营销代表的身份，生成一个具有信息量、说服力的产品描述，突出新款智能手机的创新特点。智能手机具有以下特点 [插入特点]”；

  • 结合优势：单一技术（如仅用角色 Prompt）可能导致输出 “符合身份但缺乏重点”，而多技术结合后：① 角色确保视角贴合营销场景；② 指令确保文本有说服力；③ 种子词确保聚焦 “创新” 核心；④ 任务明确目标，最终输出既专业又精准，完全匹配 “推广新手机” 的商业需求，比单一技术输出更贴合实际应用场景。
